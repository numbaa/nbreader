# NbReader 端到端测试清单

> 本文档用于手动验证各功能是否正常工作。逐一执行，标记通过/失败。

---

## 1. 应用启动

- [x] 双击启动应用（或 `dotnet run`），窗口正常显示
- [x] 窗口标题显示 "NbReader"
- [x] 顶部工具栏可见：📂 打开文件、📁 打开文件夹、🎨 演示
- [x] 底部状态栏显示 "就绪"、缩放 "100%"

---

## 2. 演示功能

- [x] 点击 🎨 演示 → 显示 3 页演示图片
- [x] 窗口标题变为 "NbReader - 🎨 演示（3 页）"
- [x] 底部状态栏显示 "1 / 3"
- [x] 按 → 翻到第 2 页、第 3 页；第 3 页时 → 不再变化
- [x] 按 ← 回到第 1 页；第 1 页时 ← 不再变化

---

## 3. 打开图片文件夹

- [x] 准备一个包含 3-5 张 `.jpg` / `.png` 图片的文件夹
- [x] 点击 📁 打开文件夹 → 选择该文件夹
- [x] 图片正确渲染，按文件名排序
- [x] 翻页正常，状态栏页码正确

---

## 4. 打开 CBZ 文件

- [x] 准备一个 `.cbz` 文件（ZIP 格式，含多张图片）
- [x] 点击 📂 打开文件 → 选择 `.cbz`
- [x] 图片正确渲染，按条目名排序
- [x] 翻页正常

---

## 5. 拖放文件

- [x] 从文件管理器拖 `.cbz` 文件到窗口 → 自动打开
- [x] 从文件管理器拖文件夹到窗口 → 自动打开

---

## 6. 缩放 & 平移

- [x] Ctrl+滚轮向上 → 放大图片，状态栏缩放百分比增加
- [x] Ctrl+滚轮向下 → 缩小图片
- [x] Ctrl+0 → 重置为 100%
- [x] Ctrl+Plus → 放大
- [x] Ctrl+Minus → 缩小
- [x] 放大后，中键拖拽 → 平移图片

---

## 7. 全屏模式 (F11)

- [x] 按 F11 → 进入全屏，窗口边框消失
- [x] 再按 F11 → 退出全屏，恢复窗口模式
