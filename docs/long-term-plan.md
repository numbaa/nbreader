# NbReader 长期计划

## 愿景

打造一款跨平台（Windows / macOS / Linux）、高性能、体验优秀的漫画阅读器，支持本地漫画文件阅读和在线漫画源浏览，成为桌面端首选漫画阅读工具。

---

## Phase 1 — MVP 本地阅读（v0.5）

**目标：** 能够打开并流畅阅读本地漫画文件。

### 1.1 文件格式支持

| 格式 | 优先级 | 说明 |
|------|--------|------|
| 图片文件夹 | P0 | 打开包含图片的文件夹，按文件名排序 | ✅ |
| CBZ（ZIP 压缩包） | P0 | 最常见的漫画格式 | ✅ |
| CBR（RAR 压缩包） | P1 | 次常见格式 |
| PDF | P1 | 部分漫画以 PDF 分发 |
| 单张图片 | P2 | 直接打开图片文件 |

### 1.2 核心阅读功能

| 功能 | 优先级 | 说明 | 状态 |
|------|--------|------|------|
| 图片渲染 | P0 | 高质量图像显示，支持 JPG/PNG/WebP | ✅ SkiaSharp + Stretch="Uniform" |
| 缩放（Ctrl+滚轮） | P0 | 平滑缩放，视口中心锚点 | ✅ |
| 拖拽平移 | P0 | 中键拖拽 | ✅ |
| 翻页（上/下一页） | P0 | 键盘 ← → PgUp PgDn Space | ✅ |
| 适应宽度/高度/页面 | P0 | 多种图片适配模式 | ⏳ 待 Phase 2 |
| 全屏模式 | P1 | 沉浸式阅读 | ⏳ 待 Phase 2 |
| 缩略图导航 | P1 | 底部缩略图条快速跳转 | ⏳ 待 Phase 2 |

### 1.3 基础 UI 框架

| 组件 | 说明 | 状态 |
|------|------|------|
| 主窗口 | 工具栏 + 阅读区 + 状态栏 | ✅ |
| 阅读器视图 | 图片显示核心区域 | ✅ ReaderView |
| 文件打开对话框 | 选择漫画文件/文件夹 | ✅ |
| 信息栏 | 当前页码、总页数、文件名 | ✅ 状态栏实时更新 |

## Phase 2 — 增强阅读体验（v1.0）

**目标：** 提供完整的本地漫画管理和沉浸式阅读体验。

### 2.1 阅读模式

| 模式 | 说明 |
|------|------|
| 单页模式 | 一次显示一页 |
| 双页模式 | 左右两页并排（适合横屏） |
| 滚动模式 | 连续垂直滚动，无缝阅读 |
| 从右到左 / 从左到右 | 支持日漫/中漫/美漫阅读方向 |

### 2.2 书架/图书馆

| 功能 | 说明 |
|------|------|
| 文件夹监控 | 扫描指定目录，自动发现漫画 |
| 封面展示 | 提取第一页作为封面，网格/列表视图 |
| 阅读进度 | 记录每部漫画的阅读位置 |
| 收藏/标签 | 分类管理漫画 |
| 搜索/排序 | 按名称、日期、进度等排序 |

### 2.3 阅读增强

| 功能 | 说明 |
|------|------|
| 书签 | 手动添加书签，快速跳转 |
| 阅读历史 | 最近阅读记录 |
| 快捷键自定义 | 用户可配置快捷键 |
| 深色/浅色主题 | 主题切换 |
| 图像增强 | 亮度/对比度/锐化调节 |
| 预加载 | 预加载下一页，减少等待 |

### 2.4 设置系统

| 设置项 | 说明 |
|------|------|
| 默认阅读方向 | R→L / L→R |
| 默认缩放模式 | 适应宽度/高度/原始大小 |
| 缓存路径 | 解压临时文件路径 |
| 翻页动画 | 开启/关闭 |
| 语言 | 多语言支持（中/英/日） |

## Phase 3 — 在线漫画 & 生态（v2.0）

**目标：** 支持在线漫画源，构建插件生态。

### 3.1 在线漫画源

| 功能 | 说明 |
|------|------|
| 插件系统 | 可扩展的在线源架构 |
| 内置源 | 预置 1-2 个公开漫画源 |
| 源管理 | 添加/删除/启用/禁用源 |
| 搜索 | 跨源搜索漫画 |
| 在线浏览 | 浏览分类/排行/推荐 |
| 在线阅读 | 流式加载，逐页阅读 |
| 下载缓存 | 在线漫画离线缓存 |

### 3.2 高级特性

| 功能 | 说明 |
|------|------|
| 阅读统计 | 阅读时长、数量统计 |
| 同步 | 跨设备同步进度（可选云服务） |
| 元数据编辑 | 编辑漫画标题、作者、标签等 |
| 导出 | 导出阅读进度/书签数据 |
| 自动分页 | 智能检测双页图并分割 |

## 技术愿景

| 维度 | 目标 |
|------|------|
| **跨平台** | Windows / macOS / Linux 原生体验 |
| **性能** | 大图秒开，内存友好，GPU 加速渲染 |
| **可扩展** | 插件架构，社区可贡献在线源 |
| **国际化** | 多语言支持 |
| **可访问性** | 键盘完全可操作，屏幕阅读器友好 |
| **开源** | MIT 许可证，GitHub 社区驱动 |

---

## 非功能性目标

- 测试覆盖率 > 70%
- 启动时间 < 2 秒
- 翻页延迟 < 100ms（预加载后）
- 支持 10000+ 页的超大漫画文件
- 安装包 < 100MB（各平台）
