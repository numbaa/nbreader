## 1. 持久化层

- [ ] 应用首次启动 → 自动创建 `nbreader.db`，含完整 Schema
- [ ] 关闭并重新打开 → 数据库不重建，数据保留
- [ ] 设置变更（方向/适应模式）→ 重启后保持

---

## 2. 书架视图

### 2.1 基础展示
- [ ] 导航栏点击「📚 书架」→ 显示书架视图
- [ ] 空书架 → 显示空状态引导（"添加监控目录或拖放漫画文件"）
- [ ] 网格视图：封面缩略图 + 标题 + 进度条
- [ ] 列表视图：切换到 ☰ 显示更多列（标题/作者/页数/进度/来源）

### 2.2 Category
- [ ] 左侧栏显示默认分类（全部）
- [ ] 「➕ 新建分类」→ 输入名称 → 分类出现在列表中
- [ ] 右键分类 → 重命名 / 删除 / 上移 / 下移
- [ ] 点击分类名 → 右侧筛选为该分类的漫画
- [ ] 拖拽漫画卡片到分类名 → 漫画加入该分类
- [ ] 同一漫画可属于多个分类

### 2.3 排序与筛选
- [ ] 排序切换：最近阅读 / 最近添加 / 标题 A-Z / 页数
- [ ] 筛选 Chip：点击标签/语言/分类 Chip → 激活筛选
- [ ] 多个 Chip 同时激活 → AND 逻辑
- [ ] 点击 Chip × → 取消该筛选
- [ ] 「+ 添加筛选」→ 弹出下拉面板，按类型分组，显示计数

### 2.4 漫画卡片交互
- [ ] 双击卡片 → 打开阅读器
- [ ] 右键卡片 → 菜单：阅读 / 下载 / 编辑元数据 / 移至分类 → / 从书架移除
- [ ] 悬停卡片 → tooltip 显示完整标题 + 作者 + 页数

---

## 3. 阅读进度

- [ ] 打开漫画，翻到第 N 页，关闭窗口
- [ ] 重新打开同一漫画 → 自动恢复到第 N 页
- [ ] 进度持久化到 SQLite（重启后仍有效）
- [ ] 书架上卡片显示进度百分比/进度条

---

## 4. 阅读历史

- [ ] 打开漫画阅读 → 历史中自动出现一条记录
- [ ] 导航栏点击「🕐 历史」→ 显示历史视图
- [ ] 历史按日期分组（今天/昨天/更早）
- [ ] 同一天内按时间倒序排列
- [ ] 同一漫画多次阅读 → 合并为一条（显示最新时间和页码）
- [ ] 悬停条目右侧 → ✕ 删除单条
- [ ] 「清除全部历史」→ 确认后清空
- [ ] 点击历史条目 → 打开漫画，断点续读

---

## 5. 本地扫描

- [ ] 设置监控目录（如 `D:\Comics\`）
- [ ] 启动或手动触发扫描 → 自动发现 CBZ/CBR/图片文件夹
- [ ] 新发现的漫画自动入库，归入"未分类"
- [ ] 封面自动提取并缓存
- [ ] 重复文件不重复入库

## 6. 回归验证（Phase 0→1 核心功能）

- [ ] CBZ/CBR/图片文件夹打开、翻页、缩放正常
- [ ] 适应模式循环切换正常（Uniform/FillWidth/FillHeight/Original）
- [ ] 单页/双页/滚动模式切换正常
- [ ] 阅读方向切换正常（L→R / R→L）+ 双页模式自动交换
- [ ] 全屏 F11 正常
- [ ] 拖放文件正常
- [ ] 错误处理正常（损坏文件、不支持的格式）
