# NbReader 端到端测试清单（Phase 1 收尾 → Phase 2）

> 当前阶段：CBR 支持 → 适应模式 → 阅读模式 → 书架/图书馆。
> 全量回归请用 [`test-checklist-full.md`](test-checklist-full.md)。

---

## 1. CBR 格式支持

- [ ] 准备一个 `.cbr` 文件（RAR 格式，含多张图片）
- [ ] 点击 📂 打开文件 → 选择 `.cbr`
- [ ] 图片正确渲染，按条目名排序
- [ ] 翻页正常，状态栏页码正确
- [ ] 拖放 `.cbr` 文件到窗口 → 自动打开
- [ ] 损坏的 `.cbr` → 状态栏显示错误提示

---

## 2. 图片适应模式

- [ ] 打开任意漫画 → 默认 Uniform 模式
- [ ] 按 F 键（或工具栏按钮）切换到 FillWidth → 图片宽度撑满视口
- [ ] 切换到 FillHeight → 图片高度撑满视口
- [ ] 切换到 Original → 1:1 像素显示
- [ ] 循环切回 Uniform
- [ ] 状态栏显示当前适应模式名称
- [ ] 切换模式时视觉中心不跳动

---

## 3. 阅读模式

### 3.1 单页模式
- [ ] 默认单页模式，一次显示一页
- [ ] 翻页一次 +1

### 3.2 双页模式
- [ ] 切换到双页模式 → 左右两页并排显示
- [ ] 第一页（封面）单独居中（右侧留空）
- [ ] 翻页一次 +2
- [ ] 最后一页若为奇数，右侧留空
- [ ] 缩放/平移对两页同时生效

### 3.3 滚动模式
- [ ] 切换到滚动模式 → 首屏快速显示 5 页，状态栏 `第 1 页  [5/97]`
- [ ] 往下滚动 → 自动加载 2 页 → 状态栏更新为 `第 3 页  [7/97]`
- [ ] 滚到底 → 所有页面加载完 → 状态栏 `第 97 页 / 共 97 页`
- [ ] 无蓝色选中框，无 L→R/R→L 方向提示，无重复适应模式文本
- [ ] 按 D 切换方向 → 不崩溃 → 按 ←/→ 不触发翻页（滚动模式只用滚轮）

---

## 4. 阅读方向

- [ ] 默认 L→R（左到右），← 上一页、→ 下一页
- [ ] 切换到 R→L（右到左），← 变为下一页、→ 变为上一页
- [ ] 双页模式下 R→L 时左右页顺序反转
- [ ] 工具栏/菜单可切换方向

---

## 5. 书架/图书馆

- [ ] 切换到书架视图 → 显示欢迎/空状态
- [ ] 添加监控目录 → 自动扫描 CBZ/CBR/图片文件夹
- [ ] 网格视图显示封面缩略图 + 标题 + 页数
- [ ] 列表视图可选
- [ ] 点击书目 → 打开阅读器并跳转到该书
- [ ] 上次阅读进度自动恢复

---

## 6. 阅读进度

- [ ] 打开漫画，翻到第 N 页，关闭窗口
- [ ] 重新打开同一漫画 → 自动恢复到第 N 页
- [ ] 进度信息持久化到磁盘（重启后仍有效）
- [ ] 在书架上显示进度百分比/页码

---

## 7. 设置 & 主题

- [ ] 打开设置页面（齿轮图标/菜单）
- [ ] 切换深色/浅色主题 → 即时生效
- [ ] 设置项持久化（重启后保持）
- [ ] 默认阅读方向可配置
- [ ] 默认适应模式可配置
