## 1. CBR 格式支持

- [x] 准备一个 `.cbr` 文件（RAR 格式，含多张图片）
- [x] 点击 📂 打开文件 → 选择 `.cbr`
- [x] 图片正确渲染，按条目名排序
- [x] 翻页正常，状态栏页码正确
- [x] 拖放 `.cbr` 文件到窗口 → 自动打开
- [x] 损坏的 `.cbr` → 状态栏显示错误提示

---

## 2. 图片适应模式

- [x] 打开任意漫画 → 默认 Uniform 模式
- [x] 按 F 键（或工具栏按钮）切换到 FillWidth → 图片宽度撑满视口
- [x] 切换到 FillHeight → 图片高度撑满视口
- [x] 切换到 Original → 1:1 像素显示
- [x] 循环切回 Uniform
- [x] 状态栏显示当前适应模式名称
- [x] 切换模式时视觉中心不跳动

---

## 3. 阅读模式

### 3.1 单页模式
- [x] 默认单页模式，一次显示一页
- [x] 翻页一次 +1

### 3.2 双页模式
- [x] 切换到双页模式 → 左右两页并排显示
- [x] 第一页（封面）单独居中
- [x] 翻页一次 +2（封面→第1对开页步长1）
- [x] 最后一页若落单，左侧显示、右侧留空
- [x] 缩放/平移对两页同时生效

### 3.3 滚动模式
- [x] 切换到滚动模式 → 首屏快速显示 5 页，状态栏 `第 1 页  [5/97]`
- [x] 往下滚动 → 自动加载 2 页 → 状态栏 `第 3 页  [7/97]`
- [x] 滚到底 → 所有页面加载完 → 状态栏 `第 97 页 / 共 97 页`
- [x] 无蓝色选中框，无 L→R/R→L 方向提示，无重复适应模式文本
- [x] 按 D 切换方向 → 不崩溃 → 按 ←/→ 不触发翻页（滚动模式只用滚轮）

---

## 4. 阅读方向

- [x] 默认 L→R（左到右），← 上一页、→ 下一页
- [x] 切换到 R→L（右到左），← 变为下一页、→ 变为上一页
- [x] 双页模式下 R→L 时左右页顺序反转
- [x] 工具栏/菜单可切换方向
