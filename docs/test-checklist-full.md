## 1. 应用启动

- [ ] 双击启动应用（或 `dotnet run`），窗口正常显示
- [ ] 窗口标题显示 "NbReader"
- [ ] 顶部工具栏可见：📂 打开文件、📁 打开文件夹
- [ ] 🎨 演示按钮仅在 Debug 模式可见，Release 模式隐藏
- [ ] 底部状态栏显示 "就绪"、缩放 "100%"

---

## 2. 演示功能（Debug 专属）

- [ ] 点击 🎨 演示 → 显示 3 页演示图片
- [ ] 窗口标题变为 "NbReader - 🎨 演示（3 页）"
- [ ] 底部状态栏显示 "1 / 3"
- [ ] 按 → 翻到第 2 页、第 3 页；第 3 页时 → 不再变化
- [ ] 按 ← 回到第 1 页；第 1 页时 ← 不再变化

---

## 3. 文件格式支持

### 3.1 图片文件夹
- [ ] 打开包含 3-5 张 `.jpg` / `.png` 图片的文件夹
- [ ] 图片正确渲染，按文件名排序
- [ ] 翻页正常，状态栏页码正确

### 3.2 CBZ（ZIP）
- [ ] 打开 `.cbz` 文件，含多张图片
- [ ] 图片正确渲染，按条目名排序
- [ ] 翻页正常

### 3.3 CBR（RAR）
- [ ] 打开 `.cbr` 文件，含多张图片
- [ ] 图片正确渲染，按条目名排序
- [ ] 翻页正常

---

## 4. 拖放文件

- [ ] 拖 `.cbz` 文件到窗口 → 自动打开
- [ ] 拖 `.cbr` 文件到窗口 → 自动打开
- [ ] 拖文件夹到窗口 → 自动打开

---

## 5. 缩放 & 平移

- [ ] Ctrl+滚轮向上 → 放大，状态栏百分比增加
- [ ] Ctrl+滚轮向下 → 缩小
- [ ] Ctrl+0 → 重置为 100%
- [ ] Ctrl+Plus → 放大
- [ ] Ctrl+Minus → 缩小
- [ ] 放大后，中键拖拽 → 平移图片

---

## 6. 全屏模式 (F11)

- [ ] 按 F11 → 进入全屏，窗口边框消失
- [ ] 再按 F11 → 退出全屏，恢复窗口模式

---

## 7. 键盘翻页

- [ ] ← 上一页
- [ ] → 下一页
- [ ] PageUp 上一页
- [ ] PageDown 下一页
- [ ] Space 下一页

---

## 8. 图片适应模式

- [ ] 默认 Uniform 等比缩放
- [ ] FillWidth → 宽度撑满
- [ ] FillHeight → 高度撑满
- [ ] Original → 1:1 像素
- [ ] 切换时视觉中心不跳动

---

## 9. 阅读模式

- [ ] 单页模式：一次一页，翻页 +1
- [ ] 双页模式：封面居中，翻页 +2，落单页左侧显示右侧留空
- [ ] 滚动模式：连续垂直排列，滚轮正常
- [ ] 模式间切换保持阅读位置

## 10. 阅读方向

- [ ] R→L：← 下页、→ 上页
- [ ] 双页模式 R→L 时左右顺序反转
